## Effect of the ROCm 10.1 server migration on challenge images

The server migration does not rewrite previously built Docker images or public registry digests. MC2 and MC3 artifacts remain immutable and unaffected.

The current provisional Match 4 Dockerfile still references the programme-confirmed ROCm 10.0 PyTorch base learned from the official MC3 kit. That base was removed from the local host during cleanup, but the Dockerfile itself remains intact. Rebuilding it would pull ROCm 10.0 again.

Do not silently replace the graded container base with ROCm 10.1 merely because the production server now runs ROCm 10.1. Host runtime and challenge-container contract are separate concerns. Use the official Match 4 base when LabLab/AMD publishes it; until then keep the adapter and container boundary provisional.
